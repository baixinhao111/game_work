# 《周一突围：DDL 战线》（MONDAY BREAKOUT: DDL FRONTLINE）

> **一句话定位**：一款专为 Z 世代打工人与高校群体打造的 **Neo-Pop 荧光波普拼贴风 × 轻肉鸽数字门射击跑酷** Mobile-First H5 小游戏——把枯燥的“红蓝门加减乘除”变成一场用冰美式、机械键盘与 AI 外挂轰碎“未读 99+”和“终极 KPI 巨兽”的反内卷爽游。

## 📚 项目文档导航

本仓库的规划与设计基线由 `docs/` 目录下的四份核心文档构成，分别对应**市场洞察、玩法策划、技术架构、研发管理**四个专业视角：

   - 拆解“打工人/反内卷”题材传播密码，确立本项目 **3 大核心设计支柱（Design Pillars）**。

2. **[02 - 游戏核心设计文档（GDD）](docs/02-game-design-document.md)**
   - 完整定义游戏微/中/大三层循环（周一到周五主线 + 周末无尽模式 + 局外 4 项永久天赋）。
   - **Art Bible 美术圣经**：完整 Hex 色板、描边投影规范、透视跑道与 0.5 秒敌我信号色标准。
   - **核心机制全表**：黄金角费马螺线阵型与视觉代理压缩算法（上限 ≤ 45 渲染单元）、8 种数字门/机关、6 大武器原型、8 个肉鸽词条与化学反应表、5 大主题 Boss 与普通怪图鉴。
   - **数值策划模型**：门算术拐点公式 `C > A / (M - 1)`、亚线性 DPS 抑胀模型 `N^0.75`、子弹合并机制、90 秒心流时间轴。
   - **Game Feel 与传播系统**：微顿帧/白闪/震屏参数、Web Audio 升调程序化音效清单、12+ 条“嘴替”弹幕吐槽逻辑、离屏导出「今日摸鱼战报」设计。

3. **[03 - 移动端网页版技术架构与工程规范](docs/03-technical-architecture.md)**
   - 技术栈选型论证与包体/性能权衡（为何放弃 Three.js / Phaser / React）。
   - 移动端视口适配方案（`100dvh` + `--app-height`、DPR 封顶 `2`、刘海安全区与防橡皮筋滚动）。
   - 触控手感工程实现：**相对位移拖拽（Relative Delta Drag）** 与单指针锁定，**领队单点碰撞锚点 + 同排双门互斥锁** 彻底解决边缘刮蹭误判。
   - 60fps 固定步长主循环、泛型对象池（零热路径 GC）、8 层 Canvas 渲染管线与离屏预渲染缓存。
   - 完整代码目录结构规划、核心 TypeScript 接口草案、数据驱动关卡 Schema、性能预算表与 iOS/Android/微信兼容 Checklist。

4. **[04 - 分阶段开发路线图、里程碑与风险管理](docs/04-roadmap-and-milestones.md)**

## 🧰 开发工具

```bash
npm run dev          # 本地开发（手机同局域网可访问）
npm run sim -- 12    # 无头数值平衡模拟：每种机器人 × 天赋等级各跑 12 局，输出胜率 / Boss 战时长 / 人数
```

- `?debug=1`：显示 FPS / 对象池面板，并在控制台暴露 `__world` 方便调试；`?level=3` 直接选中第 3 天。
- 美术素材：`OPENROUTER_API_KEY=... NODE_USE_ENV_PROXY=1 node scripts/gen-sprites.mjs boss_kpi` 用 Seedream 生成绿底原图到 `art/raw/`，再 `node scripts/process-sprites.mjs --all` 抠图导出到 `public/assets/sprites/`（`NODE_USE_ENV_PROXY` 仅在需要走代理的环境中设置）。

## 🛠️ 宏观开发工作流

本项目严格遵循**“规划先行 → 垂直切片 → 风格化注入 → 内容放量 → 真机调优”**的工业化小游戏开发节奏：

```
[M0 宏观规划与设计基线]
         │
         ▼  评审通过后启动工程初始化
[M1 核心可玩垂直切片 (Vertical Slice)]
         │  跑通：触控拖拽 + 自动射击 + 领队防误触 + 蓝红门翻转 + 基础怪 + 固定步长/对象池
         ▼  真机触控手感达标
[M2 风格化美学、打击感与“嘴替”注入]
         │  落地：Neo-Pop 波普矢量渲染 + 60ms白闪/顿帧/震屏 + Web Audio升调音效 + 嘴替弹幕
         ▼  游戏第一眼辨识度与爽感达标
[M3 完整 5 天主线、肉鸽构筑与社交战报]
         │  落地：6武器×8词条化学反应 + 周一至周五5大Boss + 无尽模式 + localStorage天赋 + 战报导出
         ▼  内容闭环与数值收敛
[M4 多端兼容性打磨、性能压测与发布就绪]
            验证：iOS Safari / Android Chrome / 微信X5真机适配 + 首包<80KB + 500人口压测60fps
```

> **当前状态**：全部规划板块（`M0–M4`）均已编码实现并通过无头数值模拟、构建体积审计与移动端竖屏实测。
