# 07 - 正式版 v1.0 总规划（定稿）

> **文档目的**：把现有游戏完整盘点一遍，对照同类成熟爆款补齐「正式版该有的东西」，给出 v1.0 的**最终范围、优先级、解锁节奏、验收标准和开发顺序**。
> **关系**：系统细节以 `docs/06`（角色 · 职级 · 设置 · 一致性框架）为准，关卡与构筑扩展以 `docs/05` 为准；本文是两者之上的总纲。
> **已确认**：角色名单 6 人（含隐藏的保洁阿姨，单局击杀 1000 只解锁）；不做「年度轮回」；不做每日 KPI 任务。

---

## 0. v1.0 一句话目标

**从「能玩 5 关的小游戏」变成「能玩一个月的正式游戏」**：第 1 局就有成长，第 10 局还有新东西，第 50 局还有追求。

| 指标 | 现在（v0.3） | v1.0 目标 |
| :--- | :--- | :--- |
| 可选角色 | 1 | 6 |
| 主线关卡 | 5（第一章） | 11（第一章 + 第二章） |
| 熟练玩家「看完全部内容」所需局数 | 约 10 局 | 约 40~60 局 |
| 长线目标 | 天赋升满 | 职级 CEO、6 角色 × 加班强度、图鉴 100% |
| 每局结算的成长反馈 | 咖啡豆 | 咖啡豆 + 绩效经验 + 图鉴发现 + 角色印章 |

## 1. 现状盘点

### 1.1 已经做好的（v0.3）

| 模块 | 内容 | 评价 |
| :--- | :--- | :--- |
| 核心玩法 | 左右拖动选门、射红门洗白、小队合体、自动开火、大招 | 稳，上手 5 秒能懂 |
| 关卡 | 周一~周五 5 关（56~86 秒）+ 周末无尽 | 节奏五段式，Boss 各有主题 |
| 敌人 | 7 种小怪 / 精英 + 5 个 Boss（多阶段、红温、主题弹幕） | Boss 已有预警、冲击和死亡演出 |
| 构筑 | 6 武器、8 词条、5 组化学反应；主线补给箱三选一 | 有雏形，但缺「越打越强」的质变 |
| 量感与爽感 | 尸潮导演（越打越多 + 两次高峰）、墨渍、爆开、顿帧、清屏章、割草里程碑 | 已到位，性能 4 倍降频下约 9 ms/帧 |
| 局外 | 4 项天赋（咖啡豆）、6 枚工牌、最佳纪录 | **偏薄**：只有数值成长 |
| 表现 | 手绘贴纸图标、动态芯片音乐（随战况加层）、嘴替吐槽、战报海报 | 有记忆点 |
| 新手 | 首局引导、功能入口按进度逐个出现 | 已到位 |
| 平台 | 小红书小工具离线包 452 KB（上限 10 MiB，建议 2 MiB） | 体积余量很大 |

### 1.2 平衡现状（模拟器，周三，每组 12 局）

| 玩家类型 | 天赋 | 胜率 | Boss 战时长 | 最大人数 |
| :--- | :---: | :---: | :---: | :---: |
| 乱晃（不看门） | 0 | 25% | 20s | 40 |
| 普通 | 0 | 92% | 20s | 143 |
| 熟练 | 0 | 100% | 20s | 214 |
| 熟练 | 6 | 100% | 13s | 297 |

结论：**第一章对新手友好度正好，但对老手没有挑战**，熟练玩家在第一章没有继续玩的理由。

### 1.3 玩家旅程诊断：玩家会在哪里流失

| 阶段 | 玩家在想什么 | 现在能给他什么 | 缺口 |
| :--- | :--- | :--- | :--- |
| 第 1 局 | 「这是什么？好玩吗？」 | 引导、周一必胜、战报 | 无明显缺口 |
| 第 2~5 局 | 「我变强了吗？」 | 天赋、下一天 | 只有数值，**没有新玩法** |
| 第 6~10 局 | 「还有什么新东西？」 | 周五、无尽 | **内容见底**，所有武器都见过了 |
| 第 10~30 局 | 「我还要追求什么？」 | 天赋慢慢升满 | **没有长线目标**，没有挑战台阶 |
| 任何时候 | 「这局我玩得怎么样？」 | 4 个数字 + 评语 | 缺复盘（谁打的伤害、拿了什么构筑） |

## 2. 对标：成熟爆款额外做了什么

只挑「单局短、即开即玩、轻肉鸽」的同类产品，看它们在核心玩法之外补了什么，以及我们怎么借。

| 参考游戏 | 它额外做了什么 | 解决的问题 | 我们怎么借 |
| :--- | :--- | :--- | :--- |
| **吸血鬼幸存者** | 每个角色 = 起手武器 + 被动；大量**靠局内挑战解锁的隐藏角色和道具**；收藏图鉴（没发现的显示问号） | 「发现感」驱动重玩，玩家为了解锁而换着玩 | 角色系统（已定）、保洁阿姨挑战解锁（已定）、**打工图鉴**（新增 §3.6） |
| **吸血鬼幸存者 / 弹壳特攻队** | **武器进化**：武器满级 + 配对道具 → 外观和弹道质变 | 单局后半段有「质变」高光，而不是数值慢涨 | 主武器 Lv.3 进化（`docs/05` §4.2），本命化学反应作为第二次质变 |
| **土豆兄弟** | 角色**取舍极强**（有优势必有代价）；每个角色单独的**危险等级 0~5** | 每个角色都值得用最高难度再打一遍，内容复用率极高 | 职业被动带代价（已定）；**加班强度 1~5 + 角色印章**（新增 §3.5），替代年度轮回作为长线追求 |
| **杀戮尖塔 / 哈迪斯** | 角色专属卡池；进阶（Ascension）/ 热度，逐级叠加规则 | 老手有台阶可爬，新手不被劝退 | 专属词条（已定）；加班强度逐级叠加规则 |
| **弓箭传说** | 升级三选一；**天使 / 恶魔交易**（扣血换强力技能） | 选择里有风险与诱惑，而不只是挑最强的 | 补给箱三选一（已有）；**加班合同**（新增 §3.8，P2） |
| **弹壳特攻队 / 向僵尸开炮** | 章节制 + 章节进度奖励；Boss / 精英掉宝箱；**结算展示伤害来源** | 每章都是一个明确的小目标；玩家知道自己的构筑在发挥作用 | 第二章（§3.4）；**本局复盘**（新增 §3.7） |
| **向僵尸开炮 / 数字门类广告游戏** | 体力、挂机收益、抽卡养成、广告与内购 | 商业化与留存 | **不做**（§4）：与「1~2 分钟摸鱼小工具」定位冲突 |

> 同类小游戏里，割草肉鸽依然是头部品类（如《向僵尸开炮》2026 年多次位列微信小游戏畅销榜前三），说明「选门 + 割草 + 三选一」这个组合本身有大众基础；我们的差异化是**打工人梗 + 零付费的纯粹爽感**。

### 3.1 角色系统（P0）

按 `docs/06` §1 落地，名单已定：

| 角色 | 解锁 | 专属主武器 | 本命化学反应 |
| :--- | :--- | :--- | :--- |
| 摸鱼实习生 | 默认 | 订书机（可局内换主武器） | 无固定（通才，靠换武器凑反应） |
| 格子衫程序员 | 职级 2 | 机械键盘 | 键盘 × 弹射 = 弹幕键盘雨 |
| 改稿设计师 | 职级 3 | 降噪耳机 | 耳机 × 冰冻 = 绝对零度静音区 |
| 画饼产品经理 | 职级 4 | 外卖无人机 | 无人机 × 分裂 = 蜂群配送风暴 |
| 拉单销售 | 职级 5 | AI 浮游炮 | 浮游炮 × 暴击 = GPT 狂暴算力 |
| 扫地僧保洁阿姨 | 隐藏：单局击杀 1000 只 | 扫帚旋风（新） | 扫帚 × 冰冻 = 拖地结冰（新） |

> 关于保洁阿姨的解锁难度：模拟器里熟练玩家打周三约 800 击杀，周五和无尽可以稳定超过 1000，所以「通关第一章的熟练玩家才能解锁」，正好是隐藏角色该有的门槛。解锁前在角色页显示剪影和「????：某局打扫得特别干净」的提示，并显示「本局最高击杀 / 1000」进度。

### 3.2 职级晋升（P0）

按 `docs/06` §2 落地。v1.0 补充两点：
- **职级奖励不只解锁角色**：每升一级都给东西（角色、工牌边框、加班强度入口、战报称号），避免「空升级」。
- **第二章的首通奖励**同样给 +80 经验，让第二章成为冲总监的主要来源。

### 3.3 局内构筑升级（P0）

| 内容 | 现在 | v1.0 |
| :--- | :--- | :--- |
| 主武器 | 补给箱可随意替换 | 专精角色锁定；强化到 Lv.3 进化（7 种进化形态，含扫帚） |
| 其他武器 | 替换主武器 | 外挂副武器：35% 火力、最多 2 个（实习生除外） |
| 词条 | 8 张通用 | 8 张通用 + 2 张新通用 + 12 张专属（每职业 2 张）；抽取权重按职业倾斜 |
| 化学反应 | 5 组「武器 × 词条」 | 5 组 + 拖地结冰 + 2 组「词条 × 词条」= 8 组 |

- 新增通用词条：**带薪病假**（每 15 秒回复 2 人，生存向）、**加班燃烧**（命中附带持续伤害，元素向）。
- 新增「词条 × 词条」反应：**超导碎冰**（冰冻 × 电弧：冻住的敌人被电到时碎裂溅射）、**燎原**（燃烧 × 分裂：分裂弹继承燃烧）。这两组让实习生之外的角色也有「第二目标」。
- 扫帚的进化形态：**气旋吸尘器**（旋风先把小怪吸到中心，再一起扫飞）。
- 进化瞬间要有演出：顿帧 + 印章「进化！」+ 武器名横幅，这是一局里第二个高光时刻（第一个是本命反应激活）。

### 3.4 第二章 · 季度冲刺（P1）

按 `docs/05` §2 的设计，第一个新章节：
- **6 关**：教学关 → 3 个组合关 → 事件关（例如「全员断网：没有补给箱」）→ 章节 Boss「季度考核评审团」（三位评委轮流出招）。
- **新动词「分岔路线」**：跑道分成「KPI 路」（红门多、收益高）和「摸鱼路」（安全、收益低）。
- **2 种新敌人**（按 `docs/05` §3 的克制矩阵挑选，各自逼玩家用不同的构筑应对）。
- **新背景音乐主题**：小调、更紧张（只是 `src/data/music.ts` 里的数据，零体积）。
- 解锁：通关第一章周五。

> **建议放进 v1.0**：只有 5 关时，6 个角色和加班强度的复用空间不够；第二章也是「职级到总监」的主要经验来源。如果开发进度吃紧，可以先发不含第二章的 v1.0，再在 2 周内追加。

### 3.5 加班强度 + 角色印章（P1，借鉴土豆兄弟的危险等级）

不做「年度轮回」，改用**每个角色独立的难度阶梯**作为长线目标：

| 强度 | 新增规则（逐级叠加） | 奖励倍率（经验 / 咖啡豆） |
| :---: | :--- | :---: |
| 0 | 正常难度 | ×1.0 |
| 1 · 偶尔加班 | 小怪血量 +20% | ×1.15 |
| 2 · 996 | 每段多 1 扇红门 | ×1.3 |
| 3 · 大小周 | 精英提前出现，尸潮多一波 | ×1.5 |
| 4 · 通宵上线 | Boss 新增一招，红温阈值提前 | ×1.75 |
| 5 · 007 | 开局人数减半 | ×2.0 |

- **解锁**：用某个角色在强度 N 通关周五，该角色解锁强度 N+1。职级 3（主管）时开放强度 1。
- **角色印章**：角色卡上显示最高通关强度，铜（1）→ 银（3）→ 金（5）。全角色金章给专属工牌「卷王之王」。
- 6 个角色 × 5 级 = 30 个目标，复用现有关卡，几乎不增加包体。
- 用模拟器验证：熟练玩家（天赋满）在强度 5 的胜率约 30~50%。

### 3.6 打工图鉴 + 工牌扩充（P1，借鉴吸血鬼幸存者的收藏）

- **图鉴分 5 页**：同事（角色）、牛马克星（敌人与 Boss）、工位装备（武器与进化形态）、职场技能（词条）、化学反应。
- 没遇到的显示剪影和「????」，第一次遇到或获得时弹出「图鉴 +1」小提示，并给 +5 绩效经验。
- 化学反应页给出**配方提示**（例如「键盘 + ？？？」），引导玩家去尝试，这是玩家自发换角色的最大动力。
- 数据全部来自现有配置表，美术复用现有贴图，开发量小。
- **工牌 6 → 20**：每个角色 1 枚（用该角色通关周五）、第二章 3 枚、隐藏成就若干（例如「一枪没开」：只靠大招和门通关周一；「摸鱼大师」：第二章全程走摸鱼路通关）。

### 3.7 本局复盘 + 战报升级（P0）

- 结算页新增**伤害来源条形图**：主武器 / 外挂 / 化学反应 / 大招各占多少（同类游戏的标配，玩家能看到自己的构筑在发挥作用）。
- 结算页新增**本局构筑一行**：「键盘 Lv.3 进化 · 弹射 · 分裂 → 弹幕键盘雨」。
- 战报海报加上：角色半身像、职级头衔、构筑标签（如「冰电流」）、一句按表现随机抽的毒舌评语。

### 3.8 加班合同（P2，借鉴弓箭传说的恶魔交易）

- 补给箱三选一时，有 15% 概率额外出现第 4 张卡「加班合同」：立刻 -20% 人数，换一张**专属词条或传说级选项**。
- 主题贴合（「拿命换绩效」），也给高手一个冒险选项。

### 3.9 挑战码（P2）

- 战报附带 6 位挑战码（关卡种子 + 角色 + 加班强度），朋友输入后可以打完全相同的一局，比较击杀和人数。
- 纯本地实现，不依赖排行榜接口；平台开放排行榜后再接入。

## 4. 明确不做（以及原因）

| 不做 | 原因 |
| :--- | :--- |
| 每日 KPI 任务 / 签到 | 已确认不做；摸鱼游戏不该变成「上班打卡」 |
| 体力、挂机收益、抽卡 | 与「随时来一局」的定位冲突，也没有联网服务 |
| 广告与内购 | 小工具场景不适合；保持零付费的纯粹体验 |
| 年度轮回（职级重置） | 已确认不做；长线追求由加班强度和图鉴承担 |
| 局外装备 / 遗物 | 推到 v1.1；规则边界已在 `docs/06` §1.4 预留（只改规则、不给武器） |
| 第三~五章 | v1.1 之后每 3~4 周更新一章，保持更新节奏 |
| 联网排行榜 | 等平台接口；先用挑战码做本地社交 |

## 5. 解锁节奏：玩家第几局能拿到什么

| 局数（约） | 解锁 / 发生 | 设计意图 |
| :--- | :--- | :--- |
| 第 1 局 | 新手引导、通关周一、**升到专员 → 解锁程序员** | 第一局就有「解锁新角色」的惊喜 |
| 第 2~3 局 | 天赋入口、图鉴入口 | 两条成长线同时出现 |
| 第 5~8 局 | **主管 → 设计师**、加班强度 1 开放 | 第一次「换个难度再打」 |
| 第 8~12 局 | 通关周五 → 无尽、**第二章** | 内容翻倍 |
| 第 12~20 局 | **经理 → 产品经理**，第一枚铜章 | 中期目标 |
| 第 25~35 局 | **总监 → 销售**，大概率解锁保洁阿姨 | 长线开始 |
| 第 40 局以上 | 副总裁 / CEO、全角色金章、图鉴 100%、20 枚工牌 | 硬核追求 |

## 6. 验收标准

| 维度 | 标准 | 怎么验证 |
| :--- | :--- | :--- |
| 角色平衡 | 各角色第一章胜率与实习生相差 ≤ ±10% | `npm run sim` 指定角色 |
| 大招有用 | 每个大招释放后，存活率或 Boss 伤害有明显提升 | 模拟器 A/B |
| 难度阶梯 | 第二章新手胜率 50~70%，熟练 90% 以上；强度 5 熟练 30~50% | 模拟器 |
| 节奏 | 第 1 局必升专员；约 30 局到总监 | 模拟器累计经验 |
| 性能 | 中端安卓满屏战斗稳定 50 fps 以上；省电模式下低端机 40 fps 以上 | 4 倍降频 + 真机 |
| 体积 | zip ≤ 2 MiB（预计约 0.8 MiB：+12 张角色图约 240 KB） | 打包审计脚本 |
| 兼容 | Chrome 61 / ES2017、CSP 无内联脚本、无音频文件 | 审计脚本 + 真机 |
| 真人试玩 | 5~10 人：80% 能说出「我最喜欢的角色」和原因 | 试玩问卷 |

## 7. 开发顺序

先做「每局都会用到」的基础，再做角色，最后堆内容。每个阶段结束都能打包试玩。

| 阶段 | 内容 | 产出 |
| :--- | :--- | :--- |
| **S1 基础** | 存档 v4 + 迁移、设置面板、职级经验与结算动画、本局复盘 | 老玩家也能立刻感到「正式版来了」 |
| **S2 角色玩法** | 6 角色逻辑、主武器锁定与进化、外挂副武器、词条倾向与专属词条、6 个大招、模拟器支持角色并完成平衡 | 核心差异化完成 |
| **S3 角色美术与界面** | Seedream 生成 12 张角色图、角色选择页、升职 / 解锁弹窗、战报升级 | 可对外展示 |
| **S4 长线系统** | 加班强度与角色印章、打工图鉴、工牌扩充 | 长线目标完成 |
| **S5 第二章** | 分岔路线 DSL、2 新敌人、6 关、章节 Boss、新音乐主题 | 内容翻倍 |
| **S6 发布准备** | 全量平衡、真机性能、P2 选做、新版宣传图 / 视频 / 更新文案 | 正式版上线 |
