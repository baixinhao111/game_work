# 01 - 市场、竞品与玩家洞察调研报告

> **文档目的**：在正式立项与编写任何一行代码前，系统拆解“数字门射击跑酷（Gate Runner / Crowd Shooter）”品类的底层成功密码、头部竞品的核心短板，以及年轻用户群体（Z 世代打工人/大学生）对“反内卷题材”的心理诉求与传播链路，从而锚定本项目的差异化破局点。

---

## 1. 品类发展脉络与标杆产品深度拆解

“过数字门打僵尸”并非凭空出现，它经历了从**纯数值跑酷**到**射击融合**，再到**买量副玩法反哺中重度变现**的三次迭代：

### 1.1 标杆产品对比分析

| 代表作品 | 品类定位 | 核心机制特征 | 商业与留存成功点 | 局限性 / 短板 |
| :--- | :--- | :--- | :--- | :--- |
| **《Count Masters》** | 纯超休闲人群跑酷 | 左右滑动选 `+ / - / × / ÷` 门扩充橡胶人数量，撞击敌方小队与塔防叠罗汉 | 极低的认知门槛；“人群滚雪球”带来的瞬间规模膨胀爽感 | 纯近战碰撞，缺乏射击火力反馈；10 关后同质化严重 |
| **《Mob Control》** | 射出式人群塔防跑酷 | 移动加农炮持续发射小人，穿过倍率门分裂增殖，压制敌方传送门 | 引入“发射+倍率叠加”和物理挤压感，连发大炮触发高频奖励多巴胺 | 节奏偏慢，缺少武器切换与弹幕割草爽感 |
| **《Last War: Survival》（Frontline Breakthrough）** | SLG 壳 + 街机射击副玩法 | 单指左右拖拽自动射击；红色负面门可通过射击翻转成蓝色正面门；击爆油桶拿武器/援军；5 小关分段式推图 | **5 阶段弧线设计**（第1关热身、2-3关密集杂兵、4-5关高压窄道与算术陷阱）；关卡间安全检查点形成“微承诺”心流；用真街机手感承接买量广告预期 | **重度买量广告味视觉**；后期强绑定 SLG 数值卡点，纯操作无法弥补战力鸿沟；部分关卡边缘碰撞粗糙 |
| **微信/抖音同类单机小游戏** | H5/小程序超休闲 | 竖屏竖直跑道 + 红蓝门 + 僵尸潮 + 看激励视频复活/翻倍 | 即点即玩、碎片化解压（1-2 分钟一局），在通勤/摸鱼场景穿透力极强 | 美术廉价拼凑（换皮美式僵尸）；无词条构筑深度；玩 3 分钟即腻；无主动分享动力 |

### 1.2 《Last War》Frontline Breakthrough 的节奏启示
从行业拆解看，《Last War》副玩法之所以让人“明知是副玩法却停不下来”，核心在于它把传统的无尽跑酷改造成了**有限关卡脉冲结构**：
1. **短平快的承诺感**：一局控制在 60–90 秒，玩家在等咖啡或坐地铁的间隙就能完整体验“弱小开局 → 滚雪球 → 极限翻盘 → 斩杀 Boss”的完整情绪曲线。
2. **Skill > Wallet 的短暂幻觉**：在局内 60 秒里，胜负主要取决于**算术路线选择、火力切门时机、走位规避伤害**，而非单纯氪金数值，给轻度玩家极强的掌控感（Agency）。
3. **逆转设计（Red-to-Blue Flip）**：把“被动躲红门”改造成“主动用火力把红门打绿/打蓝”，直接赋予了射击行为第二层战略意义——**射击不仅用于清怪，还是改造关卡收益的工具**。

## 2. 心理学与成瘾闭环拆解

为什么“单指滑动 + 算术门”会让无数玩家上头？本质上它同时触发了四种行为心理学机制：

1. **可见化的动态血条（Visible Moving Health Bar）与损失厌恶**
   - 在传统射击游戏里，血条是角落里一根静态的绿条；在人群数字门游戏里，**你身边的 80 个小人就是你的血条和火力总量**。
   - 一次走位失误擦到 `÷2` 或 `-30`，眼睁睁看着浩浩荡荡的大军瞬间蒸发一半、弹幕瞬间稀疏，这种直观的**损失厌恶（Loss Aversion）**会制造极强的刺痛感，立刻激发玩家“刚才手滑了，我能打得更好，再来一局”的强迫性重开冲动。

2. **微秒级算术博弈带来的心流（Micro-Math Flow）**
   - 面对左侧 `+20` 与右侧 `×2` 的门，玩家的大脑在 `0.5 秒` 内被迫做一次条件估算（当前人数 $> 20$ 时 `×2` 更优）。
   - 这种无需纸笔、依赖直觉判断的小决策每 5–8 秒发生一次，配合正反馈音效，让大脑保持高度专注却不觉枯燥。

3. **风险-收益空间博弈（Risk vs. Reward）**
   - 高价值门（如 `×3` 或强力武器桶）往往放在高密度僵尸或危险障碍后方，强迫玩家在“保底吃低保”和“刀尖舔血博翻倍”之间做人性抉择。

4. **极低输入门槛 × 指数级视觉输出（Low Input, Exponential Output）**
   - 输入端永远只需要一根大拇指左右拖移；但输出端在 30 秒后可以演化出**满屏弹幕、数字连跳、敌人成片炸裂**的巨大视听回报，输入产出比极大。

## 3. 竞品四大核心痛点与本项目破局策略

深入分析玩家对现有数字门游戏的吐槽（Reddit、TapTap、抖音评论区高频反馈）后，我们锁定了 4 个最致命的体验短板，并逐一制定工程与策划级解法：

| 竞品核心痛点 | 玩家真实槽点 | 本项目的精准解法 |
| :--- | :--- | :--- |
| **痛点 1：浓重的“虚假买量广告味”** | 粗糙的 3D 换皮士兵、油腻血腥僵尸、土味 UI 字体，年轻人觉得“点开像被骗进垃圾广告”，羞于截图分享。 | **独立游戏级 Neo-Pop 波普拼贴美术**：荧光便签纸 + 粗墨描边 + 贴纸硬投影 + 日程表网格跑道，视觉时髦、干净且有高辨识度，像潮玩独立小品而非买量广告。 |
| **痛点 2：中后期审美疲劳与策略单一** | 玩到第 5 关依然只是 `+10 / ×2` 换皮，子弹永远只有直线机枪，很快失去新鲜感。 | **轻肉鸽（Rogue-lite）武器进化与词条化学反应**：引入 6 种办公/生活武器原型 + 8 种弹幕词条（如“冰美式穿透 + 连锁闪电 = 超导清屏”），每一局都能打出不一样的弹幕烟花。 |
| **痛点 3：边缘碰撞误判（Collateral Error）** | 当队伍铺开到 50 人时，想走左边蓝门却被外侧一个小兵刮到中间立柱或旁边红门，瞬间同时触发两个门或被坑掉半队人，极其挫败。 | **领队单点锚定碰撞 + 同排双门互斥锁**：核心选门判定仅绑定领队中心锚点，外围小队视觉跟随且边缘擦碰豁免；同排左右门共享实例组互斥锁，穿过一扇门后另一扇立即锁定失效，**100% 杜绝“一穿二”与刮蹭冤死**。 |
| **痛点 4：缺乏情绪共鸣与社交货币** | 通关后只弹出一个冷冰冰的 `Victory + 100 金币`，玩家没有任何动力发给朋友或发小红书/朋友圈。 | **Z 世代反内卷情绪代偿 + 嘴替吐槽 + 精神状态战报**：把敌人全变成“未读 99+”“甲方改稿”“周一闹钟”；实时顶部嘴替弹幕陪玩家吐槽；局末一键生成可长按保存的**「今日摸鱼战报 / 精神状态诊断书」**海报。 |

## 4. 目标受众画像与“打工人/反内卷”传播方法论

### 4.1 核心受众画像
- **主力人群（70%）**：20–32 岁一二线城市互联网/创意/文职打工人，以及面临 DDL 与考公考研压力的在校大学生。
- **使用场景**：工位摸鱼 2 分钟、通勤地铁单手握持、午休解压、周日晚上焦虑失眠前的“电子奶嘴”。
- **审美偏好**：偏爱高对比度波普/多巴胺色系、黑色幽默梗文化（发疯文学、MBTI/精神状态自嘲、电子木鱼式幽默），排斥冗长新手引导与强制看广告。

### 4.2 “反内卷”爆款传播三定律（落地到本游戏）
结合近年来职场/反内卷爆款小游戏的出圈路径，本项目在传播基因上贯彻以下方法论：
1. **捕捉微痛点，痛点即玩法**：
   - 不写宏大苦情剧情，把每天真实发生的崩溃瞬间做成关卡和怪物——**周一的闹钟、周二的套娃周会、周三甲方的“微调一下”、周四的线上 P0 故障、周五 17:59 突然降临的 KPI 巨兽**。玩家打开前 3 秒看到怪物头顶的 `99+` 红点和弹幕里的 `收到请回复`，立刻会心一笑。
2. **高梗密度 × 0 秒上手**：
   - 无需任何教学文字，开局跑道直接提示“左右滑动：拒绝加班”。
   - 把红色减益门包装成 `紧急加班 -15`、`需求大改 ÷2`，用武器狂射把它“驳回”洗白成 `取消会议 +10`、`准点下班 ×2`，让**每一次射击都变成情绪发泄**。
3. **内置社交货币（三段式扩散路径）**：
   - **第一阶段（微信群/朋友圈截图）**：通关/阵亡后自动生成带“今日摸鱼段位（如：带薪如厕大师 / 工位战神 / 当场被优化）”“击碎改稿次数”“精神状态诊断评语”的便签风战报图，天然适合配文“今天上班全靠它续命”。
   - **第二阶段（短视频/小红书二创）**：高难度极限选门、满屏冰美式连锁闪电清屏、Boss 丝血反杀等高光画面极具观赏性，配合“嘴替吐槽”截屏极具视频切片传播潜力。
   - **第三阶段（好友比拼裂变）**：周六「无尽加班模式」成绩与“本周摸鱼榜称号”激发同僚间的调侃分享。

## 5. 本项目 3 大核心设计支柱（Design Pillars）

在后续所有的玩法取舍、视觉决策与技术实现中，必须无条件服从以下三大支柱：

1. **支柱一：一眼潮酷，绝不廉价（Neo-Pop Visual Identity）**
   - 坚持“荧光便签 × 波普拼贴”独立游戏审美，彻底远离传统买量小游戏的脏乱差；即使纯 Canvas 2D 绘制，也要通过粗描边、贴纸投影、动态缩放与粒子涂鸦做出精致的桌面潮玩质感。
2. **支柱二：零误判爽滑手感，算术与火力双线狂飙（Zero-Frustration Flow & Build Synergy）**
   - 单指拖拽跟手如丝，领队锚点与同排门互斥锁保障零冤枉扣血；局内不仅要算对门，更要靠“驳回红门 + 爆桶叠词条”打出满屏弹幕连锁烟花，越打越爽。
3. **支柱三：每 10 秒一个梗，每局一份社交战报（Relatable Satire & Social Currency）**
   - 怪物名字、门上文案、嘴替吐槽、大招台词、局末战报全链路服务于年轻人的“合法发疯”与情绪共鸣，让玩家不仅想玩下一关，还想顺手截张图发给工位对面的同事。
