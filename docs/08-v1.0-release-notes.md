## 玩家版更新文案

**《周一突围》正式版上线：从实习生干到 CEO！**

**6 位同事，6 种打法**
- 摸鱼实习生：什么武器都能换，新手最稳
- 格子衫程序员：键帽满屏弹射，大招「删库跑路」把红门全部洗白
- 改稿设计师：声波减速控场，大招「五彩斑斓黑」让时间冻结
- 画饼产品经理：蓝门人数更多，大招「画大饼」让接下来的门再加码
- 拉单销售：暴击浮游炮，大招「冲业绩」射速翻倍、必定暴击
- ？？？：某一局打扫得特别干净的人，会遇到一位扫地僧

**每一局都有成长**
- 7 级职级：每局结算涨绩效（输了也涨），升职解锁新同事、弹出任命书
- 主武器强化到 Lv.3 会进化：工业钉枪、RGB 光轴风暴、液氮冷萃、骑手军团……
- 其他武器挂成「外挂」在小队两侧帮忙开火
- 14 张新词条：每位同事都有 2 张专属词条；新增「拖地结冰」「超导碎冰」「燎原」3 组化学反应

**第二章 · 季度冲刺（6 关）**
- 分岔路线：左边 KPI 路怪多收益高，右边摸鱼路稳一点，选了就不能回头
- 限时门：倒计时结束变红门，射它可以续命
- 新敌人：抢功同事（抢走同事就跑，追上打死能抢回来）、OKR 复读机（正面护盾，弹射和穿透能绕过去）
- 章节 Boss：季度考核评审团，三位评委轮流打分

**给老玩家的长线目标**
- 加班强度 0~5：每位同事单独挑战，通关点亮铜 / 银 / 金印章，最高 ×2 绩效和咖啡豆
- 打工图鉴 62 条、荣誉工牌 23 枚

**体验优化**
- 局内底部改成操作坞：拾取提示、工作群消息、实时战况轮流显示，不再挡住大招按钮
- 新设置：音乐 / 音效分开调、震动开关、省电画质、色弱友好（红门斜纹、蓝门波点）
- 结算页新增绩效考核和本局复盘（各武器 / 外挂 / 化学反应 / 大招的伤害占比）
- 主页改成亮色波普风；Boss 受击闪烁更柔和，看得清动作

## 开发验收

| 项目 | 结果 | 方式 |
| :--- | :--- | :--- |
| 小工具包体积 | 约 0.69 MB（上限 10 MiB，建议 2 MiB） | `minitool-zip-builder/scripts/audit_artifact.py` PASS |
| 性能 | 第 9 关、200 只怪、2 外挂 + 进化武器：约 11 ms/帧（CPU 降速 4 倍） | Playwright + CDP 降速 |
| 第一章难度（普通玩家，无天赋） | 周一 100% → 周五 63% | `npm run sim` |
| 角色平衡（普通玩家，周五） | 实习生 71~81%，其他 69~100% | `scripts/sim-chars.sh` |
| 加班强度 5（熟练，满天赋） | 约 55% | `OT=5 CASE=skilled:10 npm run sim` |
| 职级节奏 | 第 1 局专员、第 5 局主管、第 11 局经理、第 24 局总监、第 51 局 CEO | `CAREER=casual npm run sim -- 70` |
| 存档兼容 | v3 → v4 自动迁移并折算经验；v4 早期存档缺字段时补默认值 | 迁移单测（esbuild 脚本） |
| 兼容性 | Chrome 61 / ES2017、CSP 无内联脚本、无音频文件 | 构建 + 审计脚本 |
