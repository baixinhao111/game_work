# 06 - 正式版 v1.0 系统设计：角色 · 职级晋升 · 设置

> **文档目的**：定义第一个正式版在「主线扩展」之外新增的三个系统：**打工人职业角色**、**职级晋升成长线**、**设置与体验**。本文是讨论稿，名单、数值与解锁节奏都可以调整，确认后再落地。
> **设计约束**：单局 1~2 分钟、小红书小工具离线包（zip 建议 2 MiB 内）、竖屏单指操作、不新增需要联网的玩法。

---

## 0. 三个系统如何咬合

```
每局结算 ──► 绩效经验 ──► 职级晋升 ──► 解锁新角色 / 新奖励
   ▲                                        │
   └──────── 换个角色，换一种玩法 ◄──────────┘
```

- **角色**负责「下一局玩起来不一样」（重玩性），也是最好的传播点：「我用程序员删库跑路通关了」。
- **职级**负责「每一局都有进度」（输了也涨经验），把角色解锁和奖励串成一条清晰的成长线；职级头衔印在工牌和战报上（传播）。
- **设置**是正式版的基本盘：照顾老手机、照顾听觉 / 色觉，让更多人能玩下去。

## 1. 角色系统：打工人职业

### 1.1 设计原则

1. **玩法差异，而非数值差异**：每个角色有 1 个被动 + 1 把**专属主武器** + 1 个专属大招。主武器决定打法流派，大招决定关键时刻的风格。
2. **没有「最强角色」**：每个角色都有明确的优势与代价，用平衡模拟器把各角色胜率控制在默认角色 ±10% 内。
3. **一看就懂的职场梗**：角色名、大招名都要让打工人会心一笑。
4. **美术成本可控**：每个角色只新画 1 张小队成员立绘（作为小队基础单位）+ 1 张选择界面半身像；5 合 1 / 10 合 1 的进化形态沿用现有素材。

### 1.2 角色名单（6 名：5 名晋升解锁 + 1 名隐藏）

| 角色 | 解锁 | 专属主武器 | 被动（优势 / 代价） | 专属大招 |
| :--- | :--- | :--- | :--- | :--- |
| **摸鱼实习生**（默认 · 通才） | 默认 | 订书机速射（**可在局内自由换主武器**） | **新人光环**：开局 +1 护盾 | **准点下班**：清屏 + 3.5 秒双倍火力（现有大招） |
| **格子衫程序员** | 职级 2 · 专员 | 机械键盘霰弹 | **递归思维**：自带「甩锅弹射」1 级 / 小队人数上限增长慢 10% | **删库跑路**：清屏，并把屏幕上**所有红门直接洗白成蓝门** |
| **改稿设计师** | 职级 3 · 主管 | 降噪耳机声波环 | **审美降压**：子弹自带冰镇减速 / 单发伤害 -10% | **五彩斑斓黑**：全场时间冻结 4 秒（敌人和 Boss 弹幕定格），冻结期间伤害 ×1.5 |
| **画饼产品经理** | 职级 4 · 经理 | 外卖无人机追踪弹 | **需求放大**：所有蓝门数值 +25% / 全武器火力 -10% | **画大饼**：立刻招募 +25% 人数，接下来 2 扇蓝门数值翻倍 |
| **拉单销售** | 职级 5 · 总监 | AI 外挂浮游炮 | **提成到手**：咖啡豆 +30%、暴击率 +10% / 开局人数 -3 | **冲业绩**：6 秒内射速 ×2.5、必定暴击（不清屏，靠火力硬冲） |
| **扫地僧保洁阿姨**（隐藏） | 挑战：单局击杀 1000 只 | **扫帚旋风**（新武器：近距离宽扇面、高穿透） | **扫帚横扫**：小怪撞上小队时 50% 概率被直接扫掉、不减员 / 射程较短 | **全部清走**：清屏，地上的墨渍全部变成咖啡豆被吸走 |

> 备选隐藏角色（以后再加）：**带资进组关系户**（挑战：无尽第 10 波；开局 +20 人和 2 护盾，但天赋不生效）。
> 冰美式穿透射线暂不绑定角色，作为所有人都能拿到的外挂副武器；以后可以留给新职业（例如「咖啡续命行政」）。

### 1.3 大招差异化示意

| 风格 | 角色 | 玩家感受 |
| :--- | :--- | :--- |
| 清屏型 | 实习生、程序员、保洁阿姨 | 被尸潮包围时一键翻盘 |
| 控场型 | 设计师 | Boss 弹幕满屏时定格，从容输出 |
| 成长型 | 产品经理 | 选门策略更重要，后期人数最多 |
| 爆发型 | 销售 | Boss 战短时间打出最高伤害 |

### 1.4 一致性框架：角色 · 局内成长 · 局外装备

角色是身份，局内的一切选择都围绕这个身份展开；局外装备只改规则、不碰武器，三层各管一件事，互不冲突。

| 层级 | 何时决定 | 管什么 | 是否变化 |
| :--- | :--- | :--- | :--- |
| **角色（身份）** | 开局前 | 专属主武器 + 被动 + 大招 | 整局不变 |
| **局内成长（本局）** | 打爆补给箱 / 击败 Boss 的三选一 | 主武器强化与进化、词条、外挂副武器 | 每局重置 |
| **局外装备（长期，后续版本）** | 开局前 | 只修改规则（护盾、补人、门的收益、经济等），**不提供武器** | 永久保留 |

**主武器：锁定 + 进化**
- 专精角色（实习生以外）整局只用自己的专属主武器，补给箱不再替换它。
- 三选一里出现「主武器强化」：同一把主武器累计强化到 Lv.3 时**进化**为新形态（例如机械键盘 → RGB 光轴风暴，见 `docs/05` §4.2）。
- **实习生是通才例外**：可以像现在一样在局内自由更换主武器，什么都能用、什么都不精，作为新手入门角色，也完整保留现有玩法。

**外挂副武器：其他武器的去处**
- 补给箱里的其他武器，对专精角色而言变成「外挂」：挂在小队两侧自动开火，约为主武器 35% 的火力，**不替换主武器**。
- 最多 2 个外挂槽；再次抽到同一外挂即升级。现有 6 种武器都能作为外挂出现，单局组合更多。
- 实习生抽到的是「换主武器」卡（他的特长），不占外挂槽。

**词条：通用池 + 职业倾向 + 专属词条**
- 通用词条所有角色都能抽到，但抽取权重向职业倾向倾斜。
- 每个角色 2 张专属词条，只有该角色能抽到：

| 角色 | 词条倾向 | 专属词条 |
| :--- | :--- | :--- |
| 实习生 | 无（最均衡） | **万金油**：换主武器时保留上一把 30% 火力作为余威 · **转正答辩**：每通过 3 扇蓝门 +1 护盾 |
| 程序员 | 弹射、分裂 | **Stack Overflow**：弹射次数翻倍 · **Ctrl+C/V**：分裂弹 +1 |
| 设计师 | 冰冻、控制 | **高级灰**：被冰冻的敌人受伤 +30% · **像素级对齐**：声波环宽度 +40% |
| 产品经理 | 成长、经济 | **需求变更**：蓝门数值额外随机 +0~50% · **PRD 加急**：无人机数量 +1 |
| 销售 | 暴击、射速 | **大客户**：暴击伤害 +60% · **提成翻倍**：击杀掉落咖啡豆 ×2 |
| 保洁阿姨 | 生存 | **地板打蜡**：墨渍区域内的敌人减速 · **垃圾分类**：扫掉的小怪有概率掉护盾碎片 |

**化学反应：每个职业天然有一套「本命组合」**
- 化学反应继续按「主武器 × 词条」触发。主武器固定后，每个专精角色都有一套明确的追求目标：程序员的键盘 × 弹射 =「弹幕键盘雨」、设计师的耳机 × 冰冻 =「绝对零度静音区」、产品经理的无人机 × 分裂 =「蜂群配送风暴」、销售的浮游炮 × 暴击 =「GPT 狂暴算力」（均为现有反应）。
- 保洁阿姨的扫帚旋风需要新增一组反应（例如扫帚 × 冰冻 =「拖地结冰」）。

**局外装备（后续版本）的边界**
- 装备只改规则：例如「工位绿萝：每 20 秒补 2 人」「带薪拉屎券：开局暂停 3 秒」。
- 装备可以带职业倾向（例如「程序员的人体工学椅：弹射命中回复护盾」），但改的永远是规则，不是武器本身，因此不会与局内的主武器 / 外挂冲突。
- 装备槽随职级解锁，见 §2.2。

### 1.5 美术与资源

- 每个角色 2 张图，用 Seedream 生成后走现有抠图流程（`scripts/gen-sprites.mjs` → `scripts/process-sprites.mjs`）：
  - **小队单位立绘**（背影奔跑持武器，256×256 WebP，约 15~20 KB）：替换小队里的 1 人单位，让整支小队变成这个职业的人；
  - **选择界面半身像**（正面表情包风，256×256 WebP）。
- 6 个角色合计约 12 张 × 20 KB ≈ **240 KB**，zip 仍远低于 2 MiB。
- 另需：保洁阿姨的新武器「扫帚旋风」弹道表现（程序化绘制即可）、外挂副武器挂在小队两侧的小图标、主武器 Lv.3 进化形态的弹道表现。

## 2. 职级晋升：局外成长线

### 2.1 绩效经验来源（每局结算）

| 来源 | 经验 |
| :--- | :--- |
| 关卡进度 | 进度百分比 × 60（打到 Boss 前 ≈ 60） |
| 击杀 | 每 20 只 +1 |
| 击败 Boss | +40 |
| 通关 | +30 |
| 首次通关某一天 | +80 |
| 无尽模式 | 每过 1 波 +25 |

一局典型收入：新手输在中途约 40~60，正常通关约 120~180。**输了也一定涨经验**。

### 2.2 职级表

| 职级 | 头衔 | 累计经验 | 解锁 |
| :---: | :--- | :---: | :--- |
| 1 | 实习生 | 0 | 摸鱼实习生 |
| 2 | 专员 | 150 | **格子衫程序员** |
| 3 | 主管 | 1200 | **改稿设计师** · 工牌升级为银色边框 |
| 4 | 经理 | 2800 | **画饼产品经理** · 开局多一次「三选一」（装备系统上线后改为解锁第 1 个装备槽） |
| 5 | 总监 | 5500 | **拉单销售** · 工牌金色边框 |
| 6 | 副总裁 | 8000 | 战报专属称号「副总裁亲自摸鱼」 |
| 7 | CEO | 11000 | 全局咖啡豆 +10% · 战报彩色封面 |

预期节奏（S1 用 `CAREER=casual npm run sim -- 70` 实测）：第 1 局升专员，约第 5 局主管，约第 13 局经理，约第 27 局总监，约第 40 局副总裁，约第 56 局 CEO。加班强度的经验倍率（`docs/07` §3.5）上线后，后期会再快一些。

### 2.3 与现有系统的关系

- **天赋（咖啡豆）保留不变**：天赋是「数值成长」，职级是「内容解锁」，两条线互不替代。
- **工牌图鉴**：职级头衔显示在工牌卡片和摸鱼战报上，例如「总监 · 工牌 NO.0404」。
- 老存档：根据已有的通关天数和击杀，**一次性折算初始经验**，老玩家进来就能直接解锁几个角色，不用从头再升。

## 3. 设置与体验

| 设置项 | 说明 |
| :--- | :--- |
| 音乐音量 / 音效音量 | 分开调节（滑块 0~100%），替代现在的单一静音按钮；静音按钮保留为快捷开关 |
| 震动反馈 | 开 / 关 |
| 画质模式 | **标准** / **省电**：省电模式减少粒子、关闭墨渍和弹幕拖尾、降低渲染分辨率，照顾老手机 |
| 色弱友好 | 开启后红门加斜线条纹、蓝门加波点，不只靠颜色区分 |
| 重新播放新手引导 | 给想再看一遍的玩家 |

入口：主菜单右上角和暂停面板里的齿轮按钮。

## 4. 界面流程

- **主菜单**：标题下方新增「职级卡片」（头衔 + 经验进度条）；「开始突围」按钮上方新增「当前角色」卡片，点击进入角色选择。
- **角色选择页**：2×3 网格，已解锁显示半身像和职业名，未解锁显示剪影 + 解锁条件（例如「职级 4 · 经理解锁」「隐藏：单局击杀 1000 只」）；选中后展示被动 / 初始武器 / 大招说明。
- **局内**：大招按钮显示当前角色的大招名（例如「删库跑路!」）。
- **结算页**：新增「绩效经验 +156」进度条动画；升职时弹出「恭喜晋升 · 主管」与解锁角色的展示卡。

## 5. 存档变更（v3 → v4）

新增字段：`selectedCharacter`、`unlockedCharacters`、`xp`、`settings`（音乐 / 音效音量、震动、画质、色弱）、`challenges`（隐藏角色进度，例如累计最高单局击杀）。旧存档自动迁移，并按 §2.3 折算初始经验。

## 6. 平衡验证

- 扩展 `npm run sim`：机器人可以指定角色，并在合适时机释放各角色的专属大招。
- 目标：每个角色在第一章各关的胜率与实习生相差不超过 ±10%；每个大招都在模拟中被证明「有用」（释放后存活率或 Boss 伤害明显提升）。

## 8. 已确认的决定

- 角色锁定专属主武器、其他武器作为外挂副武器、实习生作为可自由换主武器的通才例外（见 §1.4）。
- 角色名单定为以上 6 人；保洁阿姨的解锁挑战保持「单局击杀 1000 只」。
- 不做「年度轮回」，长线追求改由加班强度与角色印章承担（见 `docs/07` §3.5）。
- v1.0 的完整范围、优先级与开发顺序见 `docs/07-v1.0-release-plan.md`。

## 9. 实现记录：v1.0 定稿数值（与上文设计的差异）

以下数值以代码为准（`src/data/characters.ts`、`src/data/weapons.ts`、`src/data/overtime.ts`），均经过 `scripts/sim-chars.sh` 与 `OT=<强度> npm run sim` 验证。

| 项目 | 设计稿 | 定稿 | 调整原因 |
| :--- | :--- | :--- | :--- |
| 实习生被动 | 开局 +1 护盾 | 开局 +1 护盾；局内可换主武器 | 不变 |
| 程序员被动 | 自带「甩锅弹射」1 级 | 子弹自带 1 次弹射（不算词条），弹射 / 分裂伤害 +25%；蓝门 -10% | 自带词条会让「弹幕键盘雨」开局就激活；不加弹射时键盘在低人数打不动精英（周三胜率 0%） |
| 设计师 | 子弹自带冰镇；伤害 -10%；冻结 4 秒 | 子弹自带轻度减速；伤害 -25%；冻结 3 秒；大招充能 ×0.65 | 全场减速 + 每 8~10 秒一次的长冻结让胜率恒为 100% |
| 产品经理 | 蓝门 +25%；大招招募 +25% 人数、下 2 扇蓝门翻倍 | 「+」蓝门 +15%（× 门只 +6%）；大招：下 2 扇「+」门 +30%、1.5 秒无敌；充能 ×0.7 | 大招一局能放 10 次以上，永久加人会滚雪球到上千人 |
| 销售 | 咖啡豆 +30%、暴击 +10%、开局 -3 人 | 不变 | 胜率与实习生持平 |
| 保洁阿姨 | 50% 扫掉小怪；扫帚高穿透 | 30% 扫掉小怪；扫帚伤害 ×0.78、穿透 2、射程约 1 秒；充能 ×0.85 | 射程太短时打不到屏幕顶部的 Boss；放宽射程后再压伤害 |
| 外挂副武器 | 主武器 35% 火力 | 25% 火力 | 两个外挂相当于 +70% 火力，专精角色普遍压过实习生 |
| 加班强度 1~5 | 小怪 +20% 血 / 红门 / 精英提前 / Boss +25% / 人数减半 | 每级小怪血量 ×1.35~3.2、Boss ×1.2~2.6、尸潮更密、怪更快，其余规则不变 | 满天赋的熟练机器人在强度 5 依旧 100% 胜率；调整后约 55% |
| 职级门槛 | 120 / 400 / 850 / 1500 / 2400 / 3600 | 150 / 1200 / 2800 / 5500 / 8000 / 11000 | 原门槛第 7 局就到总监 |

**平衡结果（普通玩家机器人，无天赋，周五）**：实习生 71~81%，专精角色 69~100%；熟练机器人基本全胜。第二章（天赋 3 级）普通玩家 50~100%、熟练 50~100%，「全员断网」与「季度评审」最难。
